Wide min-content

Expect: open the popover. It should not exceed the width of the window. Content should scroll within the inner scroller.

HTML content

Expect: the popover contains some bold text and some italic text.

Focusable content

Expect: after opening the popover, you can focus the button by pressing the tab key. You can activate the button via keyboard or mouse; an alert will show and the popover will remain open.
